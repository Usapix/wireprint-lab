NukeRat Traffic Decoder

Расшифровка AES-GCM в исследованном формате HTTP-сообщений NukeRat. Введите ключ и тело сообщения — границы поддерживаемых блоков определятся автоматически по проверке тега.

Входные данные

128, 192 или 256 бит. Используйте только ключи из своей лаборатории.
0 байт

Результат

Как это работает

Один блок: Nonce (12 байт) + Ciphertext (переменная длина) + Authentication Tag (16 байт). Для исследованного двухблочного запроса первый блок занимает 37 байт, второй — оставшуюся часть тела. Автоматический режим проверяет оба формата. Результат выводится только при успешной проверке GCM Tag каждого блока.
